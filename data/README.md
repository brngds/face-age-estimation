# 📊 Face Age Estimation Dataset

## 📁 Dataset Overview

This project uses a facial image dataset from the ChaLearn Looking at People collection for age estimation.

The dataset contains facial images and corresponding age labels.

### 📥 Download Dataset

**[Download faces.zip from Google Drive](https://drive.google.com/file/d/1mWy7x5o9-jTZbZC9Cy0RvEGN2cgxD7xC/view?usp=drive_link)**

The dataset is hosted externally because its size exceeds GitHub's standard browser upload limit.

### 📂 Dataset Structure

After extracting `faces.zip`, the dataset should contain:

- `labels.csv` — Image filenames and corresponding ages.
- `final_files/` — Facial images used for analysis and modeling.

### 🔗 Data Source

ChaLearn Looking at People — Facial Age Estimation Dataset.

### ⚠️ Notes

The original dataset is not included directly in this GitHub repository due to its size. Download it using the link above to reproduce the analysis.

Please respect the original dataset's usage and redistribution terms.
