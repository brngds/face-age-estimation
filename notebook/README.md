# 🧠 Face Age Estimation — Jupyter Notebook

This directory contains the Jupyter Notebook for the **Face Age Estimation** Computer Vision project.

## 📓 Notebook

**`face_age_estimation.ipynb`**

The notebook covers exploratory data analysis of facial images, including dataset size, age distribution, image visualization, and considerations for training age estimation models.

## 📥 Dataset

The dataset is hosted externally on Google Drive due to its size.

[Download faces.zip](https://drive.google.com/file/d/1mWy7x5o9-jTZbZC9Cy0RvEGN2cgxD7xC/view)

## ▶️ Execution

Open the notebook in Google Colab or Jupyter Notebook and follow its instructions to access the dataset and run the analysis.

For additional project information, see the main repository README.
